# Wandao v1.3.10

v1.3.10 是一次以桌面端稳定性、错误诊断和实际登录流程为重点的维护版本。建议所有 v1.3.9 用户升级，尤其是使用飞书导入、为知笔记或 OneNote 的用户。

## 重点更新

- 飞书导入：探测目标 Wiki 后会使用最新 `Space ID` 与父节点 Token 覆盖过期配置，并保留当前表单中的 App 凭证。
- 为知笔记插件更新至 `1.0.4`：修复登录成功后提示文本与 JSON 结果粘连，导致桌面端误报“没有输出合法 JSON”。
- Windows 与后台任务：统一 UTF-8 输出，修复 OneNote 中文乱码和大量错误输出时可能卡死的问题，并增强 checkpoint 租约及 CDP 超时处理。
- 错误报告：补充脱敏后的脚本参数、任务阶段、插件与动作、耗时、退出码、结构化错误对象以及前端未处理异常，方便根据用户报告直接定位问题。
- 桌面体验：压缩首页和平台卡片占用空间，改善深色模式、键盘焦点、长错误文本及网络错误分类。
- 教程公告：将“AI 辅助学习：项目学习导师提示词”加入软件公告区，方便使用导出文档配合 AI 学习源码项目。

**升级建议**：建议升级。本版本修复登录结果误判和过期目标配置问题，并包含多项不会改变平台业务逻辑的稳定性改进。

## 下载与安装

- Windows：下载并运行 `Wandao-1.3.10-win-x64-setup.exe`。
- macOS Apple Silicon：下载本版本的 `.zip`，解压后将 `Wandao.app` 拖入“应用程序”。

macOS 首次打开如果提示“已损坏，无法打开”，请执行：

```bash
xattr -cr /Applications/Wandao.app
```

当前 Windows 和 macOS 安装包尚未配置商业代码签名，系统可能显示未知发布者或 Gatekeeper 提示。

## 插件更新

- OneNote 插件升级至 `1.0.6`。
- WPS 文档插件升级至 `1.0.1`。
- 为知笔记插件升级至 `1.0.4`。
- 安装新版主程序后，可在“插件中心”点击“一键更新全部”，确保已安装的在线插件同步到最新版本。
