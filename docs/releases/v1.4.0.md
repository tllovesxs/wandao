# Wandao v1.4.0

v1.4.0 将桌面端从 Electron 迁移到 Tauri 2，同时保持 Plugin v1、Provider v1、任务结果、用户数据和历史凭据兼容。

## 主要变化

- 使用 Rust 实现桌面主进程和任务进程管理，保留原有 32 个前端命令及事件接口。
- 保持旧任务历史、`%APPDATA%\wandao` 用户数据、Electron `safeStorage` 历史密文和插件状态兼容。
- 插件安装、替换、回滚和卸载改为原子目录事务，并在运行前校验内置插件资源。
- Windows 改用 Tauri NSIS 安装包，macOS 改用 Apple Silicon `.app` 压缩包；两端当前均为未签名发行物。
- 内置固定版本的 Python 3.11 Runtime，普通用户无需单独安装 Python、Node.js 或 Rust。

## 问题修复

- 修复钉钉文档根相对图片地址无法下载的问题。`/core/api/resources/img/...` 现在会先基于已验证的 `docs.dingtalk.com` 或 `alidocs.dingtalk.com` 页面 origin 解析为 HTTPS URL，再执行原有可信域校验和下载。
- 安全边界保持不变：协议相对地址、普通相对地址、非 HTTPS 地址和外部域名仍不会被下载。
- 修复所有平台停止后点击“继续任务”会清空当前表单的问题；从任务中心跨页继续时，会恢复已安全保存的非敏感字段，凭证仍由平台专用安全配置加载。

## 兼容性验证

- Python、Provider、前端和 Rust 自动化门禁全部通过，包括 207 项 Node.js 测试和 63 项 Rust 测试。
- Electron 兼容桥的 32 个命令、Plugin v1、Provider v1、Python 环境变量、资源路径、进度事件、停止流程和 TaskResult v1 契约已核对。
- 钉钉专项测试覆盖根相对地址解析、外域拒绝、下载前解析及 Markdown 本地路径替换。

## 安装与升级

- Windows：运行 `Wandao-1.4.0-win-x64-setup.exe`。
- macOS Apple Silicon：解压 `Wandao-1.4.0-macOS-arm64.zip`，将 `Wandao.app` 拖入“应用程序”。
- 从 1.3.x 升级时，安装程序会验证旧版注册信息，自动迁移默认或自定义目录中的旧 Electron 程序，并保留用户数据。
- 如果旧版仍在运行，安装器会提示关闭窗口和任务后直接重试，不会强制结束程序；仅在旧版安装信息损坏或无法卸载时才需要手动处理。

## 发布要求

正式发行物必须通过跨平台质量门、真实安装/资源 smoke，并附带 `SHA256SUMS`、SPDX SBOM 和 GitHub build provenance。Windows 安装包未做 Authenticode 签名，macOS 应用未做 Developer ID 签名与 Apple 公证；发布页和用户文档必须明确未知发布者与 Gatekeeper 风险，不得宣称发行物已经签名。
