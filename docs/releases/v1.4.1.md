# Wandao v1.4.1

v1.4.1 是 1.4 系列的完整修正版，包含 Tauri 2 桌面端升级、安装包大幅瘦身、旧版自动升级、任务继续体验改进和平台问题修复。

## 安装包体积

| 平台 | v1.3.10 | v1.4.1 | 缩减 |
| --- | ---: | ---: | ---: |
| Windows x64 | 119.2 MiB | 以本次构建产物为准 | 预计约 89% |
| macOS Apple Silicon | 142.2 MiB | 以本次构建产物为准 | 预计约 72% |

普通用户无需安装 Python、Node.js、Rust 或其他开发环境，下载对应系统的软件包即可使用。

## 主要更新

- 桌面端升级为更轻量的 Tauri 2 架构，保留原有平台能力、任务历史、用户设置和安全凭据。
- 支持从 1.3.x 自动升级，包括安装在自定义目录中的旧版本。
- 修复所有平台停止后点击“继续任务”会清空当前表单的问题。
- 修复部分钉钉站内图片无法保存到本地的问题，同时保留可信域名校验。
- 飞书图片教程不再占用安装包空间，改为按需加载。
- 飞书教程图片加载失败时新增单图刷新按钮，可以原位重新获取，不需要退出当前页面。

## 安装

- Windows：运行 `Wandao-1.4.1-win-x64-setup.exe`。
- macOS Apple Silicon：解压 `Wandao-1.4.1-macOS-arm64.zip`，将 `Wandao.app` 拖入“应用程序”。

当前 Windows 和 macOS 软件包尚未配置商业代码签名，系统可能显示未知发布者或 Gatekeeper 提示。安装与启动不需要联网；飞书远程教程图片需要能够访问 GitHub。
