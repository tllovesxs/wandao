# 本地文件导入钉钉文档

支持将本地 Markdown、TXT、Word（`.doc` / `.docx`）、Excel（`.xls` / `.xlsx`）和 XMind 导入钉钉在线文档。

默认行为：

- 在目标目录下创建一个与本地根目录同名的文件夹，并保留所有包含可导入文档的子目录；
- 将 Markdown 中位于本次导入目录内的本地图片上传为临时资源，再写入导入后的文档；
- 同一张本地图片在同一次任务中只上传一次；
- 不把仅用于 Markdown 图片的 `assets` 等目录错误地创建为普通钉钉目录；
- 为每篇文档记录 checkpoint，任务中断后可继续或只重试失败项。

先点击“生成导入计划”，确认目标目录、目录层级和跳过项。PDF、PPT、独立图片等目前不能作为钉钉在线文档导入，会在计划和最终报告中说明原因。

本地图片必须在所选源目录内；位于目录外、缺失或超过 25 MB 的图片默认保留原链接并产生警告。开启“本地图片处理失败时判定文档导入失败”后，该文档会改为失败，便于严格迁移验收。
