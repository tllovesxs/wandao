# Notion 插件

将 Notion 页面导出为 Markdown，支持目录批量导出、图片本地化和断点续跑。

## 功能特性

- ✅ 导出单个 Notion 页面为 Markdown
- ✅ 支持子页面批量导出（如果目标是父页面或数据库）
- ✅ 自动下载并本地化图片资源
- ✅ 断点续跑 - 跳过已导出的页面
- ✅ 保留标题、列表、代码块、表格等 Markdown 格式
- ✅ 安全 - 不提取 Cookie、Token 或 API Key

## 使用前准备

1. 确保您有权限访问目标 Notion 页面
2. 首次使用需要登录 Notion 账号
3. 建议关闭浏览器的弹出窗口拦截器

## 导出步骤

### 方法一：单页导出

1. 复制 Notion 页面链接（格式：`https://www.notion.so/workspace/Page-Name-abc123...`）
2. 在万能导中选择 "Notion 导出"
3. 粘贴页面链接
4. 选择输出目录
5. 勾选"下载图片到本地"（推荐）
6. 点击"开始导出"
7. 如需要登录，插件会打开浏览器供您完成登录

### 方法二：批量导出整个工作区

1. 打开包含多个子页面的父页面
2. 按照上述步骤操作
3. 在导出对话框中勾选"Include subpages"
4. 等待所有子页面导出完成

## 导入到 Notion

由于 Notion API 限制，目前不提供直接导入功能。推荐使用以下方式：

1. **复制粘贴**（最佳效果）
   - 打开 .md 文件，全选复制
   - 在 Notion 中粘贴，会自动识别 Markdown 格式

2. **拖拽文件**
   - 将 .md 文件拖入 Notion 页面
   - 会作为附件上传

详细指引请查看插件中的"Notion 导入"选项。

## 常见问题

### Q: 导出后图片显示不出来？
A: 确保勾选了"下载图片到本地"选项。如果仍失败，可能是图片链接需要登录才能访问。

### Q: 表格格式乱了？
A: Notion 对 Markdown 表格语法要求严格。导出后会尽量保持原样，但复杂表格可能需要手动调整。

### Q: 可以导出整个 Workspace 吗？
A: 目前支持导出单个页面及其所有子页面。如需导出整个 Workspace，需要逐个导出顶层页面。

### Q: 导出速度慢？
A: Notion 官方导出需要时间生成 ZIP 包，特别是包含大量图片时。请耐心等待。

## 技术实现

本插件通过浏览器自动化触发 Notion 的官方导出功能：

1. 打开目标页面
2. 模拟点击导出菜单
3. 选择 Markdown & CSV 格式
4. 等待下载完成
5. 解压并处理 Markdown 文件
6. 下载并本地化图片

整个过程不使用任何非官方 API，完全符合 Notion 的使用条款。
