# 思源笔记导出

本插件通过思源笔记内核 API 读取笔记本目录，并将所选文档导出为 Markdown。只连接用户自己运行且有权访问的思源实例。

## 准备

1. 启动思源笔记，并在「设置 → 关于」中复制 API Token。
2. 确认 API 地址可从运行万能导的这台电脑访问。默认地址为 `http://127.0.0.1:6806`。
3. 在插件中填写服务地址和 API Token。可选填写笔记本 ID 来缩小扫描范围，留空则显示所有笔记本，然后点击「读取目录」。
4. 在目录树中勾选需要导出的文档、父目录或整个笔记本，选择输出目录并开始导出。

## 导出内容

- 通过思源 `/api/export/exportMdContent` 导出 Markdown，保留思源内核支持的 Markdown 表达。
- 复制文档引用的 `assets/` 资源到 Markdown 旁边，并重写相对链接。
- 选择父文档时递归包含其子文档，导出结果保留原目录层级。
- 每篇文档单独保存为 Markdown，任务结束时生成 `00-导出报告.json`。

## 权限和限制

Token 会随本次任务通过 `Authorization: Token` 请求头发送给用户配置的思源服务。请只填写可信的本机或自建服务地址，并勿在 Issue、截图或日志中公开 Token。

思源加密笔记本需要先在思源中解锁。无法读取的文档或资源会记录在任务报告中。此插件只实现从思源导出，不会修改思源中的文档。
